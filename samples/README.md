# Sample Files

This folder contains sample files used during the **Microsoft Copilot Cowork Masterclass** training. These are provided as starting points for exercises and to illustrate concepts from the session.

---

## Files in This Folder

| File | Description | Used In |
|---|---|---|
| [`quarterly-sales-data.md`](quarterly-sales-data.md) | Sample quarterly sales data for the Data Story challenge | [Challenge 4](../challenges/challenge-04-data-story.md) |
| [`sample-email-thread.md`](sample-email-thread.md) | A sample email thread for Outlook exercises | General prompting exercises |
| [`project-brief.md`](project-brief.md) | A short project brief for document generation exercises | [Challenge 3](../challenges/challenge-03-document-from-scratch.md) |

---

## How to Use These Files

1. Open the relevant sample file to read the data or content.
2. Copy the relevant content into the appropriate Microsoft 365 app.
3. Use the prompts from the corresponding challenge to work with Copilot.
