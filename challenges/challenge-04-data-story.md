# Challenge 4 — Data Story

## 🎯 Scenario

You have a spreadsheet of quarterly sales data across five regions. Your manager wants to understand which region performed best, which underperformed, and what the overall trend looks like — without having to dig through the raw numbers themselves.

---

## 💡 Your Mission

Use **Copilot in Microsoft Excel** to analyze the data and generate insights in natural language.

> **Sample data to use:** See [`../samples/quarterly-sales-data.md`](../samples/quarterly-sales-data.md) for a set of sample values you can enter into an Excel spreadsheet to work with.

---

## Suggested Prompts

### Analysis Prompts
```
Which region had the highest total sales across all four quarters?
```
```
Which region showed the most improvement from Q1 to Q4?
```
```
Summarize the overall sales trend for all regions in 2-3 sentences.
```
```
Are there any regions that significantly underperformed compared to the average?
```

### Visualization Prompts
```
Create a bar chart showing total sales by region.
```
```
Add a line chart that shows the quarterly trend for all regions.
```

### Narrative Prompt
```
Write a brief executive summary of the sales performance data, highlighting the top 
performer, the underperformer, and the overall trend. Format it as a paragraph suitable 
for a leadership report.
```

---

## ✅ Success Criteria

Your analysis should:
- [ ] Correctly identify the top-performing region
- [ ] Correctly identify the underperforming region
- [ ] Describe the overall trend accurately
- [ ] Include at least one chart
- [ ] Produce an executive summary paragraph suitable for sharing with leadership

---

## 🔑 Key Learning

Copilot in Excel transforms raw data into insights using plain English questions. You don't need to be an Excel expert or know complex formulas — you just need to ask the right questions.
