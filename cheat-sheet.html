Copilot Cowork — Cheat Sheet

Your AI coworker in Microsoft 365 · keep this pinned

Which tool?

M365 CopilotA quick answer or edit, in the flow of one app.
CoworkA whole multi-step job you delegate across apps.
ScoutOngoing, proactive help that comes to you.
Team layer: Copilot Studio & Power Automate — built once, for many.

Model & cost

  • Start on Auto — picks the best model per task.
  • $ Sonnet — everyday work, best value (~$4/task).
  • $$ Opus — complex, high-stakes (~$5).
  • $$$ GPT / heavy — deep work (~$11).
  • Type /cost to see credits spent.

Great prompt = 4 parts

  • Goal — the outcome you want.
  • Context — role, audience, why.
  • Sources — the files, people, dates.
  • Format — brief, table, email…
"Prep me for my 2pm" beats "help with my meeting."

Steal these prompts

Run my daily brief: calendar, emails that need me, top 3 priorities.
Prep me for my [time] meeting — invite, attendees, related docs, a briefing.
Read the contracts in [folder] and table each renewal date.
Save this as a skill called "[name]"; trigger on "[phrase]".

Stay in control

  • It previews actions — approve before it sends/posts.
  • Outputs land in OneDrive ▸ Cowork.
  • It only sees what you can already access.
  • Turn repeat tasks into Skills to save credits.
AD
Delegate the outcome — not every step. Describe what "done" looks like and let Cowork plan the work.
